Prompt Forge · 动漫提示词生成器

单文件 HTML 工具，双击即用，不需要安装。面向 Anima（Danbooru 标签流）和 MOSS-Image（自然语言 + 布局）两套提示词体系，内置标签库、角色库、预设、模板、反向生成、本地 ComfyUI 生图。

快速开始

  1. 双击 提示词生成器.html（推荐 Edge / Chrome）
  2. 顶栏下方选模型：Anima 或 MOSS-Image
  3. 左栏点标签加入；也可以从「角色库」「预设」「模板」「随机组合」一键套用
  4. 右栏确认输出，点「复制」拿提示词
  5. 要出图：点「🎨 生图」→ 连本机 ComfyUI（见下文「本地 ComfyUI」）

两套模型体系

  • Anima：Danbooru 标签流，自动带质量前缀 masterpiece, best quality, score_7, safe；画师标签加 @；支持括号权重语法。
  • MOSS-Image：自然语言优先，隐藏画师分类；右栏自动出现「MOSS 自然语言草稿」（5 种句式模板）；支持布局 JSON 生成。
  • 切换时输出前缀、负向词、可见分类都会跟着换，选中的标签保留。

标签库（约 2742 个 / 25 个分类）

  • 分类：质量与风格、画师、构图、镜头、光影、人物基础、身材、姿势动作、表情、发型、面部、服饰、配饰、场景、天气、道具、负面、其他与题材、文本、NSFW 四子类、怪物与异种、MOSS 专属
  • 拼音搜索：中文、英文、分类名，以及全拼 chuxia / 首字母 cx
  • 收藏与最近：右键标签收藏（★ 显示在标签上）；分类导航有「★ 收藏」「🕘 最近」
  • 权重：Shift+点击 = 权重 1.2；已选列表可上下移、改权重、删除
  • 补充标签：原来独立的「补充标签」已按内容并入对应分类
  • NSFW：拆成「身体 / 服装 / 姿势动作 / 玩法道具」四个子类
  • 怪物与异种：触手、史莱姆、拉米亚、魅魔、龙娘、精灵、兽人、狼人、幽灵、机甲少女等 73 个 XP 向标签
  • 随机组合：从各分类随机抽一组；「含 NSFW」开关打开后自动带 sensitive / nsfw / explicit 评级并追加成人标签，关闭则完全排除

角色库（1401 个角色 / 40+ 作品）

  • 分组页签：全部 / 🎮 游戏 / 📺 番剧 / 🎤 VTuber / ⭐ 收藏 / 🕘 最近
  • 角色少的小 IP 已并入「热门番剧」「其他游戏」，不单独占一行
  • 热门番剧角色都标注了来源作品（卡片上显示「葬送的芙莉莲」「咒术回战」等）
  • 支持收藏（卡片右上角 ☆）、随机角色、按中/英/拼音搜索
  • 套用角色会自动带上发色、瞳色、特征、服装、体型等外观标签

预设 / 模板 / 布局

  • 预设：299 个 / 14 类（场景、动作、氛围、光影、构图、服装、题材、表情、天气、特效、道具、双人多人等）
  • 卡片上的 ＋ 可把多个预设叠成组合，一次「叠加应用」
  • 预设编辑器可以选分类，自建预设随 localStorage 保存
  • 模板：12 个成品配方（角色卡、四格漫画、竖排四格、活动海报、杂志封面、电影剧照、信息图、专辑封面、游戏主视觉、绘本跨页、商品广告、角色三视图）
  • 「套用」只加标签；「套用+布局」连布局 JSON 一起生成
  • 布局 JSON（MOSS）：输出栏「🧩 布局」选画布与版式，生成 abs_centralized + yxyx 的 bbox 布局，直接粘进布局工作流（记得工作流分辨率设成同一尺寸）

反向生成

  • 输出栏「↩ 反向」：按当前正向标签推导负面提示词，先清空负面再填入
  • 标准版约 75 个（模型基线 + 通用核心 + 按分类映射 + 冲突互斥 + 语义规则 30 对 + 质量反推）
  • Shift+点击 = 全量版（110+ 个，补齐画质、噪点、文字、构图、光影等）
  • 与正向重复的词自动跳过；正向要 NSFW 时自动剔除负面里的 nsfw / safe 等压制词

体检 / 历史 / 输出

  • 🩺 体检：检查缺主语、缺质量词、正负重复、标签冲突、标签过多/过少等 8 项，可逐条或一键修复
  • 📜 历史：每次复制自动记录（最多 40 条），支持置顶 📌、勾选两条对比、与当前状态对比
  • 输出锁定：勾选后输出框可手动编辑，不会再被标签覆盖
  • 🧹 清空：一键清空全部正向 + 负面 + 已套用角色
  • 复制 / 生图都读取你手改后的最终输出

本地 ComfyUI 集成

方式 A：同源部署（推荐 · 免代理 / 免 bat）

把本 HTML 放进 ComfyUI 的前端静态目录，用 http://127.0.0.1:8188/文件名 打开。页面与 ComfyUI 同源，所有 API 直接可用，不需要代理脚本、也不需要改 ComfyUI 启动参数。

  • Windows 便携版路径：ComfyUI_windows_portable\python_embeded\Lib\site-packages\comfyui_frontend_package\static\
  • pip / 整合包安装：<Python>\Lib\site-packages\comfyui_frontend_package\static\
  • 复制进去后打开 http://127.0.0.1:8188/提示词生成器.html，工具会自动识别同源并连接
  • 发给别人：把 html 发给对方，对方放进同样的目录、用 8188 打开即可，零配置、零脚本
  • 注意：同源页面和 file:// 的 localStorage 是分开的，第一次用可以用「导出 / 导入」迁移配置

方式 B：本地代理（file:// 双击打开时用）

为什么不能直连 8188：ComfyUI 的 origin_only_middleware 会对 Sec-Fetch-Site: cross-site 的请求返回 403，且默认没有 CORS 头，所以 file:// 页面直连 8188 一定失败。

解决办法：本地代理 comfy-proxy.mjs，把 127.0.0.1:8199 转发到 8188，并补 CORS 头、去掉触发 403 的请求头。

  • 启动：双击桌面 启动ComfyUI代理.bat（或 node comfy-proxy.mjs）
  • 生成器默认就连 http://127.0.0.1:8199，打开「生图」点「测试/连接」即可
  • 重启电脑后需要重新双击一次代理 bat（想开机自启就把它放进 shell:startup）

模型加载方式：生成器模型下拉左侧可切换

  • 「整合包」：Checkpoint（如 anything-v5）
  • 「UNET 分离」：UNET + 文本编码器 + VAE（如 Anima Base v1.0：anima-turbo-v1.1 + qwen_3_06b_base + qwen_image_vae），会自动按底模家族配对 qwen 编码器与 VAE

其他：

  • 「🎯 套用当前模型参数」：Anima → 10 步 / CFG 1 / euler + simple / 1024²；MOSS → 30 步 / CFG 3 / er_sde / 1024²
  • 「🖼 历史出图」：记录最近 30 次生成的图片地址、参数和提示词，可载回参数或复制提示词
  • 需要完全复刻自己的 ComfyUI 工作流：在「高级：自定义工作流」里粘贴 API 格式 JSON

快捷键

  • Ctrl / Cmd + K：聚焦搜索
  • Ctrl / Cmd + Enter：复制输出
  • /：聚焦搜索
  • Esc：关闭最上层弹窗
  • Shift + 点击标签：权重 1.2
  • Shift + 点击 ↩ 反向：全量反向

数据与备份

  • 所有选中、收藏、历史、自定义角色/预设都存在浏览器 localStorage
  • 左栏底部「导出 / 导入」可整体备份迁移（包含设置、收藏、历史）
  • 工作区 backups/ 目录保存了每次大改前的版本快照，出问题可以直接拷回去
  • 「清空」会重置 localStorage 里的全部数据，谨慎使用

常见问题

连不上 ComfyUI？ 先确认 ComfyUI 在跑（浏览器打开 127.0.0.1:8188 能看到界面），然后双击桌面「启动ComfyUI代理.bat」，回到生成器刷新页面再点「连接」。

点连接提示 403？ 说明请求走了直连 8188，被 ComfyUI 的跨站检查拦了，把地址改成 http://127.0.0.1:8199 或双击代理 bat。

拼音搜不到？ 首字母搜索至少输入 2 个字母；多音字按常用读音匹配。

数据会丢吗？ 只存在当前浏览器；清缓存/换浏览器会丢，重要配置请用「导出」存一份 JSON。

换电脑怎么迁移？ 拷贝 提示词生成器.html + 导出的 JSON；ComfyUI 模型和代理脚本也要一起带。

文件

  • 提示词生成器.html：主程序（单文件，约 900 KB）
  • README.md：完整功能说明（本文件）
  • 导入说明.md：部署与配置导入步骤
  • AGENT_HANDOFF.md：给自动化 Agent 的部署 / 验收文档
  • comfy-proxy.mjs：file:// 场景的本地 ComfyUI 代理（8199 → 8188）
  • 启动ComfyUI代理.bat：双击启动代理
  • icon.ico：图标（桌面快捷方式用）
  • backups/：历史版本快照

> 交接给他人：直接发送「PromptForge-交接包.zip」，对方解压后按 导入说明.md 或 AGENT_HANDOFF.md 操作即可。
